# senvahealth.com

The website for Senva and its at-home saliva test, Senva Health. Plain HTML and CSS, published as they are by statichost.eu. The pages are generated by a small Python script in `_build/`, so the header, footer and shared parts stay identical on every page.

Only the `public/` folder is published. Everything else in this repository (this README and `_build/`) stays off the website.

| Page | What it is |
|---|---|
| `public/index.html` | Home page for customers: what Senva Health is, the kit, how it works, what makes it different, what you get (with a sign-up card), the science in brief, questions, About Senva (founders and the newest news) and the waiting list |
| `public/about.html` | Team, support from Umeå University, our journey (milestones), how we're testing the test (with a sign-up card), investors and partners |
| `public/science.html` | Article on epigenetic clocks and biological age, with links to the research |
| `public/privacy.html` | Privacy notice for the waiting list |
| `public/404.html` | Shown for addresses that don't exist |

The menu at the top lists the home page's sections in the order they appear: How it works, What you get, Science, Questions and About. The Science and About sections each lead on to their own page, and on those pages their menu item links to the page itself.

| Other files | What they are |
|---|---|
| `public/styles.css` | All styling |
| `public/site.js` | Phone menu, highlighting the menu item for the section in view, the waiting-list forms and the question helper |
| `public/assistant.js` | The question helper's answers. Generated by the build: don't edit it by hand |
| `public/img/` | Photos (WebP in two or three sizes each) and the senva and senva health logos (SVG) |
| `public/fonts/` | The brand fonts, Corben for headings and IBM Plex Sans Light for text, self-hosted (SIL Open Font Licence, see `fonts/OFL.txt`), so no visitor data goes to Google Fonts |
| `public/favicon.ico`, `icon.svg`, `icon-192.png`, `apple-touch-icon.png`, `logo.png` | Browser, phone and search-engine icons, made from the Senva symbol. Google Search uses `favicon.ico`, `icon-192.png` or `apple-touch-icon.png` (it doesn't read SVG). Keep these file names, because Google asks for stable icon addresses |
| `public/og.png` | Image shown when the link is shared, for example on LinkedIn |
| `public/robots.txt`, `public/sitemap.xml` | Tell search engines what to index. The build updates `sitemap.xml` |
| `public/_headers` | Security headers for statichost.eu |
| `statichost.yml` | Tells statichost.eu to publish `public/` without a build |
| `_build/` | The script and content that generate the pages |

## Changing the site

Edit the content in `_build/`, then rebuild from this folder:

```
python3 _build/build_site.py
```

- Text on the home and About pages (steps, what you get, questions, milestones, team): `_build/build_site.py`.
- The science article and the privacy notice: `_build/science.main.html` and `_build/privacy.main.html`.
- Links: `_build/config.json` (the founders' LinkedIn profiles, shown on the About page; a Senva company page on LinkedIn, which only goes into the data search engines read; the questionnaire; an analytics snippet). An empty value leaves that element out.
- Styling and behaviour: edit `public/styles.css` and `public/site.js` directly, then rebuild. The pages ask for both files with a version made from their contents (for example `styles.css?v=1a2b3c4d`), so visitors' browsers fetch the new files instead of using old copies. The brand colours are at the top of `styles.css`: deep teal `#053033`, teal `#0E5A67`, mint `#2AC8A5` and pale mint `#A6EDDE`.
- The logo in the header is `_build/logo.svg.txt`; the footer and the kit section use `public/img/senva-logo.svg` and `public/img/senva-health-logo.svg`. All three come from the brand files (`Senva logopaket.ai`).
- The build writes the five pages, `assistant.js` and `sitemap.xml` into `public/`, and sets today's date in `sitemap.xml` for each page that changed.

Don't edit the `.html` files by hand: the next build overwrites them.

## Preview of the content still needed

```
python3 _build/build_site.py ../senva-preview --preview
```

This writes a full copy of the site next to this folder, with a dashed box for every picture and fact still needed. Open `index.html` in it by double-clicking. The preview is marked noindex and must not be uploaded: the script refuses to write it inside this repository.

## Adding a milestone

In `_build/build_site.py`, add a line to `MILESTONES` (date, label, title, text) in date order. The newest milestone appears under "Latest" on the home page; all of them appear on the About page.

## Question helper

The "Ask a question" button in the corner of every page opens a small helper. It answers with written answers only and never makes anything up: the answered questions in `FAQ`, plus the extra answers in `ASSIST_EXTRA`, both in `_build/build_site.py`. Each answer has a list of words that point to it (`ASSIST_KW` for the questions, `kw` for the extras). When only part of a question matches, it says the answer is the closest it has. When nothing matches, the helper offers to email Antón (the test and the science) or Åke (investors, partners and press) from the visitor's own email program. It runs in the browser: nothing typed into it is stored or sent anywhere.

To add an answer, add it to `ASSIST_EXTRA` with the words people might use, then rebuild. When a question in `FAQ` gets an answer, add its words to `ASSIST_KW`; the build stops and says so if you forget.

## Waiting list

All forms post to the Formspree form `xzdopbyo`. If that form is restricted to certain domains in Formspree, add `senvahealth.com`. Each sign-up also records:

- `source`: which form was used (the card on the home page, the main form, or the card on the About page).
- `campaign`: the campaign tags on the link the visitor arrived by. Tag links in posts and pitches like `https://senvahealth.com/?utm_source=linkedin&utm_campaign=skeric`.
- `referrer`: the site that linked to Senva, if any.

Nothing is stored on visitors' devices.

## Search engines

- Each page has its own title, description and canonical address, and structured data (JSON-LD): the organisation with its founders, the questions, the About page and the science article with named authors.
- Add the site to Google Search Console as a Domain property (verified with a TXT record at Namecheap) and submit `https://senvahealth.com/sitemap.xml`. Bing Webmaster Tools can import it from Search Console.
- Links from other sites help most: Umeå University, Umeå University Holding, the Innovation Office, KTH Innovation, SKERIC and the founders' LinkedIn profiles.
- Senva is the company and Senva Health is the test kit. Name the kit "Senva Health" wherever people might search for it, because "Senva" alone is also a US company's name.
