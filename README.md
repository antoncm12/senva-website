# senvahealth.com

The Senva website. Plain HTML and CSS, published as they are by statichost.eu. The pages are generated by a small Python script in `_build/`, so the header, footer and shared parts stay identical on every page.

| Page | What it is |
|---|---|
| `index.html` | Home page for customers: what Senva is, how it works, what you get, the science in brief, what makes Senva different, questions, waiting list, and About Senva (founders and latest news) |
| `about.html` | Team, backing from Umeå University, our journey (milestones and LinkedIn), how we're testing the test, investors and partners |
| `science.html` | Article on epigenetic clocks and biological age, with links to the research |
| `privacy.html` | Privacy notice for the waiting list |
| `404.html` | Shown for addresses that don't exist |

The menu at the top lists the home page's sections in the order they appear: How it works, What you get, Science, Questions and About. The Science and About sections each lead on to their own page, and on those pages their menu item links to the page itself.

| Other files | What they are |
|---|---|
| `styles.css` | All styling |
| `site.js` | Phone menu, highlighting the menu item for the section in view, LinkedIn posts that load on request, and the two waiting-list forms |
| `img/` | Photos and logos, as WebP in two or three sizes each |
| `fonts/` | Self-hosted Cormorant Garamond and Outfit (SIL Open Font Licence, see `fonts/OFL.txt`), so no visitor data goes to Google Fonts |
| `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `logo.png` | Browser, phone and search-engine icons |
| `og.png` | Image shown when the link is shared, for example on LinkedIn |
| `robots.txt`, `sitemap.xml` | Tell search engines what to index. The build updates `sitemap.xml` |
| `_headers` | Security headers for statichost.eu |
| `statichost.yml` | Tells statichost.eu to publish the files without a build |
| `_build/` | The script and content that generate the pages |

## Changing the site

Edit the content in `_build/`, then rebuild from this folder:

```
python3 _build/build_site.py .
```

- Text on the home and About pages (steps, what you get, questions, milestones, team): `_build/build_site.py`.
- The science article and the privacy notice: `_build/science.main.html` and `_build/privacy.main.html`.
- Links: `_build/config.json` (LinkedIn profiles, the Senva company page, the SKERIC post, the questionnaire, an analytics snippet). An empty value leaves that element out.
- The build sets today's date in `sitemap.xml` for each page that changed.

Don't edit the `.html` files by hand: the next build overwrites them.

## Preview of the content still needed

```
python3 _build/build_site.py ../senva-preview --preview
```

This writes a full copy of the site next to this folder, with a dashed box for every picture and fact still needed. Open `index.html` in it by double-clicking. The preview is marked noindex and must not be uploaded: keep it outside this repository.

## Adding a milestone

In `_build/build_site.py`, add a line to `MILESTONES` (date, label, title, text) in date order. The two newest milestones appear under "Latest from Senva" on the home page; all of them appear on the About page.

## LinkedIn post

On LinkedIn, click ⋯ on the post, choose "Embed this post" and copy the code. Put its `src` in `LI_SKERIC_EMBED`, its `height` in `LI_SKERIC_HEIGHT` and the post's address in `LI_SKERIC_URL` in `_build/config.json`, then rebuild. The post only loads when a visitor clicks "Show the post", so the site stays free of cookies until then.

## Waiting list

Both forms post to the Formspree form `xzdopbyo`. If that form is restricted to certain domains in Formspree, add `senvahealth.com`. Each sign-up also records:

- `source`: which form was used (the band in the middle of the home page, or the main form).
- `campaign`: the campaign tags on the link the visitor arrived by. Tag links in posts and pitches like `https://senvahealth.com/?utm_source=linkedin&utm_campaign=skeric`.
- `referrer`: the site that linked to Senva, if any.

Nothing is stored on visitors' devices.

## Search engines

- Each page has its own title, description and canonical address, and structured data (JSON-LD): the organisation with its founders, the questions, the About page and the science article with named authors.
- Add the site to Google Search Console as a Domain property (verified with a TXT record at Namecheap) and submit `https://senvahealth.com/sitemap.xml`. Bing Webmaster Tools can import it from Search Console.
- Links from other sites help most: Umeå University, Umeå University Holding, the Innovation Office, KTH Innovation, SKERIC and the founders' LinkedIn profiles.
- Use "Senva Health" in profiles, email signatures and press, because "Senva" alone is shared with a US sensor maker.
