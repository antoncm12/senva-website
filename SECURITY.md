# Security policy

If you find a security problem in senvahealth.com or in this repository, please tell us privately rather than opening a public issue. You can:

- email us at the contact address on senvahealth.com, or
- use "Report a vulnerability" on this repository's Security tab, if it's available.

Please include what you found, how to reproduce it, and what it could affect. We aim to reply within a week, and we'll keep you informed until it's fixed.

Please don't access, change or delete other people's data while testing, and give us reasonable time to fix the problem before you tell anyone else.

This repository contains only the public website. It should hold no secrets, and no personal data apart from the founders' published names, photos and contact details. If you find anything else, please tell us straight away.
